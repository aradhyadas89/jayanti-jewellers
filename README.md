# Jayanti Jewellers — Official Portfolio Website

An aesthetic, responsive, and performance-optimized luxury jewellery portfolio website for **Jayanti Jewellers**, situated in Khukur Daha, Jiakhali, West Bengal.

Built with **Next.js 16 (App Router & Turbopack)**, **React 19**, **Tailwind CSS v4**, and **Lucide Icons**.

## ✨ Features & Architecture

1. **Enterprise-Grade Luxury Design & Typography**:
   - Clean, architectural restraint: Replaced casual floating pill badges with refined editorial overlines, fine 1px dividers, and crisp museum-grade frames.
   - Palette: Warm Ivory Silk (`#faf8f5`), Alabaster (`#ffffff`), Cashmere Stone (`#f5f1eb`), Deep Espresso Onyx (`#171513`), and Antique Royal Gold (`#8c6834`, `#c1a06e`).
   - Fonts: Optical-sized editorial serif (`Cormorant Garamond`) paired with modern system sans (`Geist`).
   - Cohesive Actions: Sharp bespoke buttons with elegant uppercase tracking, clear hierarchy, and zero visual clutter.
2. **Interactive Portfolio Showcase**:
   - Filterable categories: *Royal Bridal Heritage*, *Everyday Lightweight Gold*, *Bengali Artistry & Pola*, *Certified Diamonds*, and *Pure 92.5 Silver & Pooja*.
   - Direct 1-tap "Inquire on WhatsApp" action with prefilled product title and weight.
3. **Purity & Hallmarking Section**:
   - Detailed breakdown of the 3-sign BIS Hallmark: BIS Triangle, 22K916 fineness, and 6-digit laser HUID code.
4. **Bespoke Atelier & Old Gold Exchange**:
   - 4-step custom bridal workflow from reference photo/sketch to final hallmarked piece.
   - Transparent computerized old gold valuation guarantee.
5. **Interactive Location & Embed Map**:
   - Embedded Google Map view with pin coordinates `(22.4745658, 87.7497901)`.
   - 1-click turn-by-turn navigation link to Google Maps.
6. **Mobile First & Sticky Conversion Bar**:
   - Floating bottom quick-action bar on mobile for instant calls (`tel:09734805821`), WhatsApp chat, and GPS directions.
7. **SEO & Structured Data**:
   - Full OpenGraph metadata and Schema.org `JewelryStore` JSON-LD schema with complete weekly timetable, address, geo coordinates, and contact details.

## 🛠️ Development & Build Commands

```bash
# Run local dev server with Turbopack
npm run dev

# Run strict ESLint verification
npm run lint

# Production build with static prerendering
npm run build

# Start production server
npm run start
```
